# Future Productivity — Flutter To-Do App

A premium offline-first Flutter productivity app with a distinctive future-productivity visual identity.

## Features
- Material 3 + glassmorphism-inspired UI
- Animated productivity ring and task completion feedback
- Creative task categories and priority intensity
- Swipe right to complete, swipe left to delete
- Search and animated filters
- Upcoming task timeline
- Premium dark mode
- SharedPreferences persistence
- Fully offline: no Firebase, backend, or APIs
- Cloud APK build via GitHub Actions

## Run

```bash
flutter pub get
flutter run
```
